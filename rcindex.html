PROJECT 01

TicketGo

Bus Ticket Booking · Frontend Web Project
About the project

TicketGo is a bus ticket booking frontend project designed to provide a simple and practical bus reservation experience. Users can select their preferred bus journey based on date and time, enter their name and phone number, and book available tickets.

Features
  • Bus ticket booking
  • Date and time selection
  • Passenger name and phone number
  • Available spot ticket display
  • Waiting list functionality
  • Booking confirmation
  • Unique ticket ID
  • Ticket cancellation using phone number
  • Waiting-list status
